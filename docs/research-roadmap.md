# Research roadmap

## Current educational demonstration
- Compare logistic regression and random forest on the Wisconsin Diagnostic Breast Cancer feature dataset
- Report cross-validation and held-out metrics
- Document limitations, data provenance and reproducibility

## Planned computational biology study
- Select a public gene-expression dataset with clear licensing and sample metadata
- Define a biologically meaningful research question and outcome
- Check for duplicates, batch effects, class imbalance and leakage
- Establish a baseline model and evaluate with sample-level stratification
- Explore interpretation, uncertainty and external validation where possible

These are planned steps, not claims of completed research or publications.
