# Stage 4 — External validation and biological interpretation readiness

**Status: audit framework implemented. No independent-cohort accuracy or biological biomarker validation is claimed.**

## Scientific motivation
Stages 2 and 3 used the same UCI/TCGA Pan-Cancer RNA-Seq dataset. Strong within-dataset performance does not demonstrate independent-cohort generalization.

## Critical data limitation
The UCI feature columns are anonymized. Their numerical positions are **not** sufficient to align the model with a new expression dataset. Before external validation, we need a verified, documented mapping between the original feature columns and gene identifiers. Do not fabricate such a mapping.

## Stage 4 outputs
- `stage4_external_audit.py`: checks unique feature and sample IDs, disjoint cohorts, supported labels, finite expression values and complete one-to-one feature mapping.
- `test_stage4_audit.py`: tests safe blocking and compatibility checks.
- `results/stage4_readiness.json`: machine-readable readiness assessment, generated by GitHub Actions.

## Required external cohort
Obtain an independently collected RNA-Seq cohort with biological gene IDs, tissue labels and sample provenance. Document platform, normalization, batch effects, patient overlap, inclusion criteria and licensing. Harmonize genes **only after** a defensible mapping to the training features exists.

## Next experiment
Once identity and provenance checks pass, lock preprocessing and model parameters, apply the training-fitted model to the independent cohort, and report class-level metrics with uncertainty and cohort limitations. If mapping cannot be established, train a **separate model on an annotated dataset**, clearly distinguishing that from external validation of the original model.

## Research integrity
A passing technical compatibility audit is not a scientific validation. No claim of independent validation, clinically useful prediction, named biomarkers or pathway enrichment is supported at this stage.
